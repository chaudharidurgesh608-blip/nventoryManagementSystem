Key Project Features

Designed according to BCA project guidelines & industry best practices

Role-Based Security

Powered by ASP.NET Core Identity with secure password hashing and JWT token authorization for Admin and User roles.

Stock In & Stock Out

Strict business logic protects against negative stock issuance while maintaining a comprehensive transaction audit trail.

Low Stock Warning System

Real-time status badges automatically tag items as In Stock, Low Stock, or Out of Stock to prevent warehouse shortages.
